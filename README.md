# simple-cdn

虚拟主机CDN 是一款专为虚拟主机环境设计的轻量级 CDN 源码。纯 PHP 原生实现，无需数据库、无需 Composer、无需额外服务器环境，一行代码即可植入任意现有 PHP 网站，实现页面缓存加速与资源分流。

本仓库为媒体库功能加强的配套源码，提供页面缓存加速与资源分流能力。

---

## 📁 仓库结构

| 文件/目录 | 说明 |
|-----------|------|
| `cdn.php` | CDN 核心入口（已加密混淆） |
| `router.php` | 内置服务器路由（本地测试用） |
| `config.default.php` | 默认配置 |
| `config.example.php` | 用户配置模板（复制为 `config.php` 使用） |
| `.htaccess` | Apache 重写规则 |
| `Cache/` | 缓存文件类 |
| `Plugin/` | 插件基类与管理器 |
| `Plugins/` | 内置插件（UAFilter / CacheControl / Gzip） |
| `lib/` | 核心库（Auth / Stats / Region / HealthChecker / PurgeLog / CacheWarmer） |
| `admin/` | 后台管理页面 |
| `nodes.json` | CDN 节点配置示例 |

## 🚀 快速开始

1. **克隆仓库**：
   ```bash
   git clone https://github.com/songliannv/simple-cdn.git
   ```

2. **上传文件**：将仓库中的所有文件上传到虚拟主机站点根目录。

3. **创建配置**：
   ```bash
   cp config.example.php config.php
   ```

4. **修改配置**：编辑 `config.php`，设置 `origin`（源站域名）和 `admin_password`（后台密码）。

5. **设置权限**：确保 `runtime-cache/`、`stats/` 目录对 Web 运行用户可写。

6. **访问后台**：`http://你的域名/admin/`，使用设置的密码登录。

## ✨ 主要功能

- 页面整页缓存，原 PHP 脚本不再重复执行
- 智能资源分流（cdn / origin / bypass）
- 多节点 CDN + 地区智能调度（IP 自动判断，302 切换到最近节点）
- 节点健康检查（离线节点自动跳过）
- 主站一键清理缓存 + 节点联动清理（HTTP purge 接口）
- 缓存预热同步（清理后自动预热热门 URL）
- 清理日志审计（CSV/JSON 导出）
- 多节点负载均衡（least_rt / round_robin / weighted）
- 后台管理：清缓存 / 命中率统计 / 插件开关 / 节点管理

## 🔒 加密说明

核心 PHP 文件已进行免费等级的加密混淆处理（去注释、空白压缩、Base64封装），无需任何PHP扩展，可在普通虚拟主机运行。配置文件保持明文，便于用户自行修改。

极少数虚拟主机可能在`php.ini`中禁用了`eval()`，如部署后页面空白，请联系主机商开启，或使用明文版本。
